# Coffee-Shop-Sales
An interactive Excel dashboard built to analyze 149K+ coffee shop transactions and generate meaningful business insights. The dashboard evaluates total sales, customer footfall, average bill, product performance, store-wise sales, peak ordering hours, category contribution, order-size distribution, and weekday trends.
# Tools Used
- Microsoft Excel
- PivotTables 
- PivotCharts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
# Files
- Coffee Shop Sales.xlsx – Raw sales dataset containing transaction-level coffee shop sales data.
- Excel Project Dashboard.xlsx – Final Excel dashboard containing KPIs, PivotTables, PivotCharts, and interactive slicers for sales analysis.

# Dashboard Insights
- $698.8K+ total sales from 149K+ transactions.
- Coffee was the highest-selling category.
- Barista Espresso was the top-selling product.
- April recorded the highest monthly sales.
- Thursday had the highest order volume.
- Hell’s Kitchen had the highest store sales.
